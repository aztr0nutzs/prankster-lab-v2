# PRODUCT_DIRECTION.md

Last updated: 2026-06-01

## Direction

Prankster Lab is now positioned as **Prankstar Voice Meme Studio + Sound Stash**.

Main promise:

> Play hundreds of prank sounds, generate funny voice clips, and save your own custom prank audio.

## Product Pillars

### Sound Stash

Sound Stash remains a core feature, not a secondary archive. It contains the bundled prank sound library, favorites, searchable categories, generated Voice Lab clips, generated Sound Forge clips, and future imported/custom clips.

### Voice Lab / Jokes

Voice Lab is the primary monetizable and viral feature. Users choose a synthetic voice preset, type a joke or comment, tune pitch/speed/volume/effect settings, generate local audio, preview it, and save it to Sound Stash.

### Core

Core is the quick launch and reactor screen. It keeps the interactive reactor, random-safe playback, current sound state, catalog counts, quick links to Stash and Jokes, and Stop All.

### Forge

Forge is an advanced and experimental sound effect generation tool. Stable Forge clips save into Sound Stash using the generated/custom sound model.

### System

System contains settings, diagnostics, validation visibility, generated clip cleanup, audio controls, safety acknowledgement, and app information.

## Primary Navigation

The bottom dock is:

- Core -> `home`
- Stash -> `library`
- Forge -> `forge`
- Jokes -> `voice_lab`
- System -> `system`

Timer, Randomizer, Packs, and Prank Messages are secondary tools only.
