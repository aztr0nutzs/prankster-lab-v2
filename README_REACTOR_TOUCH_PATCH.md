# PrankStar Reactor Touch Responsiveness Patch

This update enhances the existing PrankStar bot-screen HTML without changing the overall layout identity.

## Added

- Bigger, clearer reactor overlay buttons and labels.
- Extra mapped touch zones for every reactor slot: r1 through r7.
- Press, drag, and hold interactions.
- Hold-to-charge meter with full charge release feedback.
- Reticle pop, spark bursts, floating zone labels, micro-jolt animation, and stronger video flash.
- Improved reactor selector legibility.

## Keep path

Use:

```text
app/src/main/assets/prankstar/prankstar_new_home_bot_screen.html
```

Open in Android WebView with:

```text
file:///android_asset/prankstar/prankstar_new_home_bot_screen.html
```
